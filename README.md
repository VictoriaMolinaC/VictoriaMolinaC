## Proyecto destacado

### [Progreso Sobrio](https://progresosobrio.cl)

<a href="https://progresosobrio.cl"><img src="https://raw.githubusercontent.com/VictoriaMolinaC/progreso-sobrio/main/.github/banner.png" alt="Progreso Sobrio: app open source, web y Android, 100% offline, para acompañar la abstinencia de sustancias"></a>

App gratuita y open source (MIT), para la web y Android, que acompaña el día a día de personas en proceso de abstinencia de sustancias, pensada para Chile, con la línea 1412 de SENDA integrada.

Construida 100% offline por diseño: sin backend, sin servidor, sin analytics. Todos los datos viven solo en el dispositivo de quien la usa. La app Android ni siquiera tiene permiso de internet, y puede traer el pulso y el sueño de una pulsera desde Health Connect, con una vista previa antes de usarlos.
